Análisis de productividad en la preparación de pedidos (picking)
Proyecto final de Ciencia de Datos de la Universidad Ean. Usamos Google Colab para revisar y preparar datos de picking (preparación de pedidos), comparar el volumen de operaciones por día y tipo de tarea, y mostrar los resultados en gráficos. El análisis ayuda a entender cómo cambia la carga de trabajo en una bodega.
